# 历年真题说明

本目录用于存放 CSP-J 初赛历年真题的解析摘要与注意事项。

## 建议做题顺序
1. 2025 年（最新，难度参考价值高）
2. 2024 年
3. 2023 年
4. 2022 / 2021 年

## 2025 年简要特点
- **选择题**：数据类型范围、位运算、递归、哈夫曼树、图的度、组合计数、逻辑运算、斐波那契周期、string、引用传递、杨辉三角路径、冒泡交换次数、进制、完全二叉树、队列模拟。
- **阅读程序**：
  1. 两两互质三元组 + GCD
  2. 排序去重 + 滑动窗口 / DP 求最少分段（最大值-最小值 ≤ k）
  3. 最长公共子序列（LCS）模板
- **完善程序**：
  1. 字符串解码（类似 a3b2 → aaabb）
  2. 摩尔投票法变形（找多数「精明人」）

整体难度中等偏上，对代码理解要求较高。

## 使用建议
- 先自己限时做完再看解析
- 重点记录自己容易忽略的边界与改动影响
- 对照本仓库的知识点清单查漏补缺
