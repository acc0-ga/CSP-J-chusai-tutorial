# 树状数组进阶应用

在掌握基础的单点修改 + 前缀和查询之后，常见的进阶用法有：

1. **求逆序对**
2. **区间修改 + 单点查询**（差分数组 + 树状数组）
3. **区间修改 + 区间查询**（两个树状数组）
4. 配套练习题

---

## 一、用树状数组求逆序对

### 问题定义
给定一个长度为 n 的数组 a[1..n]，求有多少对 (i, j) 满足 i < j 且 a[i] > a[j]（逆序对）。

### 思路
从**后往前**遍历数组：
- 每遇到一个数 x，先查询当前树状数组中「有多少个数比 x 小」（这些数都会与 x 构成逆序对）
- 然后再把 x 插入树状数组（出现次数 +1）

为了处理数值范围较大的情况，通常先离散化。

### 完整可运行代码

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
#include <cstring>
using namespace std;

const int MAXN = 100010;
int tree[MAXN];
int n;

int lowbit(int x) { return x & -x; }

void update(int i, int v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);
    }
}

int query(int i) {
    int res = 0;
    while (i > 0) {
        res += tree[i];
        i -= lowbit(i);
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    vector<int> a(n + 1), b(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        b[i] = a[i];
    }

    // 离散化
    sort(b.begin() + 1, b.end());
    int m = unique(b.begin() + 1, b.end()) - (b.begin() + 1);
    for (int i = 1; i <= n; i++) {
        a[i] = lower_bound(b.begin() + 1, b.begin() + 1 + m, a[i]) - b.begin();
    }

    memset(tree, 0, sizeof(tree));
    long long ans = 0;

    // 从后往前
    for (int i = n; i >= 1; i--) {
        // 查询比 a[i] 小的数有多少个（已经插入的）
        ans += query(a[i] - 1);
        // 插入 a[i]
        update(a[i], 1);
    }

    cout << ans << endl;
    return 0;
}
```

**输入示例**：
```
6
5 4 2 6 3 1
```
**输出**：`10`（逆序对数量）

## 二、区间修改 + 单点查询

### 思路：差分数组 + 树状数组

原数组 a，差分数组 d：
- `d[1] = a[1]`
- `d[i] = a[i] - a[i-1]`（i > 1）

则 `a[i] = d[1] + d[2] + ... + d[i]`（前缀和）

**区间 [l, r] 全部加 v**：
- `d[l] += v`
- `d[r+1] -= v`

用树状数组维护差分数组 d，就能支持：
- 区间修改 O(log n)
- 单点查询（求前缀和）O(log n)

### 代码模板

```cpp
void range_add(int l, int r, int v) {
    update(l, v);
    update(r + 1, -v);
}

int point_query(int i) {
    return query(i);   // 差分数组的前缀和就是原数组的值
}
```

## 三、区间修改 + 区间查询

需要维护两个树状数组（推导略，直接给模板）。

设差分数组为 d，则：

前缀和 sum(1~x) = Σ (x-i+1) * d[i] = (x+1) * Σd[i] - Σ(i*d[i])

因此需要两个树状数组：
- tree1 维护 d[i]
- tree2 维护 i * d[i]

### 完整模板

```cpp
long long tree1[MAXN], tree2[MAXN];

void update(long long* tree, int i, long long v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);
    }
}

long long query(long long* tree, int i) {
    long long res = 0;
    while (i > 0) {
        res += tree[i];
        i -= lowbit(i);
    }
    return res;
}

// 区间 [l, r] 加 v
void range_add(int l, int r, long long v) {
    update(tree1, l, v);
    update(tree1, r + 1, -v);
    update(tree2, l, l * v);
    update(tree2, r + 1, -(r + 1) * v);
}

// 前缀和 1~x
long long prefix_sum(int x) {
    return (x + 1) * query(tree1, x) - query(tree2, x);
}

// 区间和 [l, r]
long long range_sum(int l, int r) {
    return prefix_sum(r) - prefix_sum(l - 1);
}
```

## 五、学习路线建议

1. 先把基础单点修改 + 前缀和跑通（上一篇示例）
2. 手写一遍逆序对代码并测试
3. 理解差分数组后，实现区间修改 + 单点查询
4. 最后再看区间修改 + 区间查询（两个树状数组）

把 lowbit 的跳跃方向真正画熟，后面这些扩展都会变得自然。
