# 洛谷 P3374 & P3368 树状数组模板题详解

这两道题是树状数组最经典的入门模板题，强烈建议先手写通过再继续学进阶。

---

## 一、P3374 【模板】树状数组 1

**题目大意**：  
给定一个长度为 n 的数组（初始有值），支持两种操作：
1. 单点修改：把第 x 个数加上 k
2. 区间查询：求第 l 到第 r 个数的和

**数据范围**：n, m ≤ 5×10⁵，需要 O(log n) 的数据结构。

### 解法
直接使用基础树状数组：
- `update(x, k)`：单点加
- `query(r) - query(l-1)`：区间和

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500010;
long long tree[MAXN];
int n, m;

int lowbit(int x) {
    return x & -x;
}

void update(int i, long long v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);
    }
}

long long query(int i) {
    long long res = 0;
    while (i > 0) {
        res += tree[i];
        i -= lowbit(i);
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        update(i, x);          // 初始化：直接当单点修改做
    }

    while (m--) {
        int op;
        cin >> op;
        if (op == 1) {
            int x;
            long long k;
            cin >> x >> k;
            update(x, k);
        } else {
            int l, r;
            cin >> l >> r;
            cout << query(r) - query(l - 1) << "\n";
        }
    }
    return 0;
}
```

**注意点**：
- 下标从 1 开始
- 初始化时直接多次调用 `update` 即可
- 用 `long long` 防止溢出

## 二、P3368 【模板】树状数组 2

**题目大意**：  
给定一个长度为 n 的数组（初始有值），支持两种操作：
1. 区间修改：把第 l 到第 r 个数全部加上 k
2. 单点查询：询问第 x 个数的值

### 解法：差分数组 + 树状数组

设原数组为 a，差分数组为 d：
- `d[1] = a[1]`
- `d[i] = a[i] - a[i-1]` (i ≥ 2)

则 `a[x] = d[1] + d[2] + ... + d[x]`（差分数组的前缀和）

**区间 [l, r] 全部加 k**：
- `d[l] += k`
- `d[r+1] -= k`

用树状数组维护差分数组 d，即可实现：
- 区间修改 O(log n)
- 单点查询 O(log n)

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500010;
long long tree[MAXN];
int n, m;

int lowbit(int x) {
    return x & -x;
}

void update(int i, long long v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);
    }
}

long long query(int i) {
    long long res = 0;
    while (i > 0) {
        res += tree[i];
        i -= lowbit(i);
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    long long prev = 0;
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        update(i, x - prev);   // 构建差分数组
        prev = x;
    }

    while (m--) {
        int op;
        cin >> op;
        if (op == 1) {
            int l, r;
            long long k;
            cin >> l >> r >> k;
            update(l, k);
            update(r + 1, -k);
        } else {
            int x;
            cin >> x;
            cout << query(x) << "\n";   // 差分数组前缀和 = 原数组的值
        }
    }
    return 0;
}
```

**关键点**：
- 初始化时用「当前值 - 前一个值」构建差分
- 区间加的时候只需要两处 update
- 单点查询直接 query 即可

## 三、两题对比总结

| 题目   | 操作类型                  | 核心思想             | 树状数组维护的内容 |
|--------|---------------------------|----------------------|--------------------|
| P3374  | 单点修改 + 区间查询       | 基础树状数组         | 原数组本身         |
| P3368  | 区间修改 + 单点查询       | 差分数组 + 树状数组  | 差分数组           |
