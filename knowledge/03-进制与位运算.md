# 进制与位运算 · 深入解析（含陷阱）

CSP-J 初赛选择题和阅读程序中，位运算是高频考点。很多同学不是不会算，而是容易踩「优先级」「符号位」「移位」这些坑。

本文重点讲**陷阱**和正确理解方式。

---

## 一、位运算基础回顾（必会）

| 运算符 | 含义 | 例子（二进制） |
|--------|------|----------------|
| `&` | 按位与 | 1101 & 1011 = 1001 |
| `\|` | 按位或 | 1101 \| 1011 = 1111 |
| `^` | 按位异或 | 1101 ^ 1011 = 0110 |
| `~` | 按位取反 | ~0000...0101 = 1111...1010（补码） |
| `<<` | 左移 | 0000 0101 << 2 = 0001 0100 |
| `>>` | 右移 | 有符号数通常是算术右移（高位补符号位） |

常用技巧：
- `x & 1` 判断奇偶
- `x & (x-1)` 消除最低位的 1
- `x & -x` 取最低位的 1（补码性质）
- `x >> 1` 等价于除以 2（向下取整，注意负数）

## 二、最常见的 8 个陷阱

### 陷阱 1：运算符优先级（最高频！）

位运算优先级**低于**比较运算符和加减，但**高于**逻辑运算符 `&&` `||`。

```cpp
int a = 5, b = 3;
if (a & b == 1)   // 实际是 a & (b == 1)，结果几乎总是错的
if ((a & b) == 1) // 正确写法
```

**记忆口诀**：有 `& | ^` 和 `== != < >` 一起出现时，**一定要加括号**。

真题风格例子：
```cpp
cout << (255 & 254);   // 254
cout << 255 & 254;     // 可能因为优先级变成奇怪的结果（取决于上下文）
```

### 陷阱 2：有符号数的右移（算术右移 vs 逻辑右移）

C++ 中对**有符号整数**执行 `>>`，大多数编译器是**算术右移**（高位补符号位）。

```cpp
int x = -8;          // 二进制补码 ...11111000
cout << (x >> 1);    // 结果通常是 -4（高位补1）
```

如果想要逻辑右移（高位补0），需要先转成无符号类型：
```cpp
unsigned int y = x;
cout << (y >> 1);
```

**考试注意**：题目如果给的是负数右移，优先按「补符号位」理解。

### 陷阱 3：左移溢出与未定义行为

- 左移位数 ≥ 类型位数 → 未定义行为（考试中一般不会出极端情况，但要知道）
- `1 << 31` 对 32 位有符号 int 会变成最小负数（符号位变成1）
- 推荐写 `1LL << 31` 或 `1ULL << 31` 避免问题

```cpp
int a = 1 << 31;     // 危险，结果是 -2147483648
long long b = 1LL << 31; // 安全
```

### 陷阱 4：`~` 取反后的结果

`~x` 是按位取反，对有符号数会改变符号，而且结果通常是 `-(x+1)`（补码性质）。

```cpp
int x = 5;       // ...00000101
cout << ~x;      // -6
```

很多人误以为 `~5` 是 2 或什么正数，其实是负数。

### 陷阱 5：把位运算当成逻辑运算

```cpp
if (a & b)       // 只要 a&b 的结果非0就为真（按位）
if (a && b)      // 逻辑与，短路，只关心真假
```

`a = 2, b = 4` 时：
- `a & b` → 0 → 假
- `a && b` → 真

考试里经常用这个区别出判断题。

### 陷阱 6：负数的位运算表示（补码）

计算机用补码存负数。  
`-1` 的二进制是全 1（`...11111111`）。  
所以：
```cpp
cout << (-1 & 7);   // 7
cout << (-1 >> 1);  // 仍然是 -1（算术右移）
```

记住：`-1` 跟任何数做 `&`，结果还是那个数（在位数够的情况下）。

### 陷阱 7：混合类型运算

`int` 和 `unsigned int` 混合运算时，会把有符号数转成无符号再计算，容易出现「大数」。

```cpp
int a = -1;
unsigned int b = 1;
cout << (a > b);    // 可能输出 1（true），因为 a 被转成很大的无符号数
```

初赛出现频率不高，但阅读程序里如果出现 unsigned 要警惕。

### 陷阱 8：`x & (x-1)` 与 `x & -x` 的含义搞混

- `x & (x-1)`：消除最低位的 1（常用于判断是否为 2 的幂、统计 1 的个数）
- `x & -x`：只保留最低位的 1（lowbit）

例子：
```cpp
x = 12;          // 1100
x & (x-1) = 8;   // 1000
x & -x = 4;      // 0100
```

## 三、真题风格练习（带陷阱）

**题 1**  
`cout << (255 & 254);` 输出是？  
答案：254  
解析：255 = 11111111，254 = 11111110，与完还是 254。

**题 2**  
`int x = 7; if (x & 1 == 0)` 这个条件会怎么走？  
答案：`1 == 0` 先算，得到 0，然后 `x & 0` → 0，条件为假。  
正确写法必须加括号：`if ((x & 1) == 0)`。

**题 3**  
`int a = -16; cout << (a >> 2);` 结果通常是？  
答案：-4（算术右移，高位补 1）

**题 4**  
下列哪个可以把最低位的 1 消掉？  
A. x & (x+1)  B. x & (x-1)  C. x | (x-1)  D. x ^ (x-1)  
答案：B

---

## 四、备考建议

1. 看到 `& | ^` 和比较、逻辑运算符在一起，**第一反应加括号**。
2. 遇到负数移位，优先按「算术右移」理解。
3. 把 `~x = -(x+1)`、`-1` 全 1 这两个性质记牢。
4. 做阅读程序时，涉及位运算的变量变化一定要在纸上写出二进制（至少低 8 位）。

- 优先级不够，括号来凑
- 右移看符号，负数补 1
- 取反变负，~x = -x-1
- & 和 && 不一样，一个按位一个逻辑
