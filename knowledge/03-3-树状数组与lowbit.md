# 树状数组中 lowbit 的具体用法

树状数组（Binary Indexed Tree / Fenwick Tree）是一种高效维护**前缀和**、支持单点修改的数据结构。  
它的时间复杂度是 O(log n)，核心就依赖 **lowbit**。

---

## 一、树状数组是什么？

我们想解决两个问题：
1. **单点修改**：把第 i 个位置的值加上 v
2. **前缀和查询**：求前 i 个位置的和（sum(1~i)）

普通数组：修改 O(1)，查询 O(n)  
前缀和数组：查询 O(1)，修改 O(n)  
树状数组：修改和查询都是 **O(log n)**

---

## 二、lowbit 在树状数组里扮演什么角色？

每个节点 `i` 管辖一段连续区间，区间长度正好是 `lowbit(i)`。

```
节点 i 管辖的区间是：[i - lowbit(i) + 1 , i]
```

例子（1-based 下标）：

| i | 二进制 | lowbit(i) | 管辖区间 |
|---|--------|-----------|----------|
| 1 | 001    | 1         | [1,1]    |
| 2 | 010    | 2         | [1,2]    |
| 3 | 011    | 1         | [3,3]    |
| 4 | 100    | 4         | [1,4]    |
| 5 | 101    | 1         | [5,5]    |
| 6 | 110    | 2         | [5,6]    |
| 7 | 111    | 1         | [7,7]    |
| 8 | 1000   | 8         | [1,8]    |

可以看到：
- 2 的幂次节点管辖很长的区间（像一棵树的高层节点）
- 奇数节点只管辖自己

这就是为什么叫“树状”数组。

## 三、两个核心操作如何使用 lowbit

### 1. 单点修改（update）

把位置 `i` 的值加上 `v`，需要更新所有**管辖了 i 的节点**。

这些节点的下标是：`i`、`i + lowbit(i)`、`i + lowbit(i+lowbit(i))` ... 一直到不超过 n。

```cpp
void update(int i, int v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);   // 跳到下一个需要更新的节点
    }
}
```

**为什么加 lowbit？**  
加 lowbit 正好跳到“父亲”节点（管辖范围更大的节点）。

### 2. 前缀和查询（query）

求 1~i 的和，只需要把若干个区间拼起来。

这些区间的右端点是：`i`、`i - lowbit(i)`、`i - lowbit(i-lowbit(i))` ... 一直减到 0。

```cpp
int query(int i) {
    int sum = 0;
    while (i > 0) {
        sum += tree[i];
        i -= lowbit(i);   // 跳到前一个区间
    }
    return sum;
}
```

**为什么减 lowbit？**  
减 lowbit 正好跳到“前一个不重叠的区间”。

## 四、完整模板（1-based）

```cpp
const int MAXN = 100010;
int tree[MAXN];
int n;

int lowbit(int x) {
    return x & -x;
}

// 单点加
void update(int i, int v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);
    }
}

// 前缀和 1~i
int query(int i) {
    int res = 0;
    while (i > 0) {
        res += tree[i];
        i -= lowbit(i);
    }
    return res;
}

// 区间和 l~r
int range_sum(int l, int r) {
    return query(r) - query(l - 1);
}
```

## 五、图解理解（强烈建议动手画）

以 n=8 为例，修改位置 3（+1）：

```
需要更新的节点：3 → 4 → 8

3 的 lowbit=1，3+1=4
4 的 lowbit=4，4+4=8
8 的 lowbit=8，8+8=16 > n，停止
```

查询前缀和 1~6：

```
需要累加的节点：6 → 4

6 的 lowbit=2，6-2=4
4 的 lowbit=4，4-4=0，停止
```

正好把 [5,6] + [1,4] 拼成 [1,6]。

---

## 六、为什么效率是 O(log n)？

每次 `i += lowbit(i)` 或 `i -= lowbit(i)`，都会让 i 的二进制表示中至少有一个 1 被消除或进位，  
最多操作次数 ≈ 二进制位数 ≈ log₂n。

## 八、易错点

1. **下标必须从 1 开始**（0 的 lowbit 是 0，会死循环）
2. `update` 是 `i += lowbit(i)`，`query` 是 `i -= lowbit(i)`，方向千万别反
3. 查询区间 [l,r] 要用 `query(r) - query(l-1)`，注意 l=1 时的边界
4. 数组大小至少开到 n+10，防止越界

---

## 九、一句话总结

> 树状数组利用 lowbit 把数组组织成一棵隐式的树。  
> 修改时沿着“父亲”方向跳（+lowbit），  
> 查询时沿着“前一个区间”方向跳（-lowbit）。

把 lowbit 的原理（补码）和这两个跳跃方向记住，树状数组就真正掌握了。
