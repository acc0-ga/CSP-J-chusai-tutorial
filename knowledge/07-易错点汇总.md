# CSP-J 初赛易错点汇总

整理自历年真题与常见丢分点，建议考前重点过一遍。

---

## 一、选择题高频易错

### 1. 数据类型与范围
- `int` 大约 ±2×10⁹，`unsigned int` 最大约 4×10⁹
- `long long` 大约 ±9×10¹⁸
- 计算 2³²-1 时容易记成有符号最大值
- 溢出问题：大数相乘、阶乘、斐波那契等要想到用 long long

### 2. 位运算
- `&` `|` `^` 优先级低于比较运算符，复杂表达式要加括号
- `255 & 254 = 254`（常见考法）
- 左移右移对符号位的影响（有符号数右移是算术右移）

### 3. 进制转换
- 八进制/十六进制转十进制时位数算错
- 混合进制运算（如十进制 + 八进制）要先统一进制
- 前缀：`0` 开头是八进制，`0x` 是十六进制

### 4. C++ 语法细节
- **引用传递 vs 值传递**：函数参数加 `&` 才会修改原变量
- `string` 可以和 `char` 用 `+` 连接，但 `length()` 与 `size()` 相同，末尾没有 `\0` 计入长度
- `for` 循环里修改循环变量导致少循环/多循环
- 逻辑运算符短路：`&&` 左边为假右边不执行，`||` 左边为真右边不执行

### 5. 数据结构概念
- 有向图：入度总和 = 出度总和 = 边数
- 完全二叉树叶子节点数 ≈ ⌈n/2⌉ 或 n - ⌊n/2⌋
- 哈夫曼树带权路径长度计算时深度容易数错
- 栈后进先出，队列先进先出，模拟过程要画图

### 6. 数学与组合
- 组合数计算容易漏减（正难则反）
- 斐波那契取模要找周期（Pisano period）
- 杨辉三角/网格路径 = 组合数 C(m+n, m)

## 二、阅读程序易错点

### 1. 边界与循环次数
- 三重循环 `i < j < k ≤ n` 时，n=2 根本进不了最内层
- 空数组、n=0、n=1 的特殊情况
- `unique` 去重后长度变化，后续循环用新长度

### 2. 变量跟踪
- 递归函数要一层层展开或找规律，不要只看表面
- 数组下标从 0 还是从 1 开始要看清楚
- 修改某行代码后，结果是否真的改变（很多判断题考这个）

### 3. 算法理解错误
- 把「最多选几个」理解成「最少段数」
- LCS 和 LIS 的关系搞混
- 滑动窗口左指针移动条件写反（`>` 还是 `≥`）

### 4. 常见陷阱代码
- 删除某个 `&&` 条件后结果变大还是变小
- 递归 GCD 参数写反导致死循环或错误
- 未排序就做滑动窗口，答案会偏大

## 三、完善程序易错点

### 1. 字符串处理
- 判断下一个字符是否是数字前，必须先判断 `i+1 < length`，否则越界
- 多位数解析：`count = count * 10 + (s[i] - '0')`
- 循环结束后 `i` 是否需要再自增

### 2. 摩尔投票 / 多数元素类
- 初始候选者和计数的设置
- 计数归零时要更换候选者
- 「互相抵消」的条件判断容易写反

### 3. 通用填空技巧
- 先看功能描述和注释，再看空前后的代码
- 优先考虑边界（空输入、最大值、负数）
- 选项中有明显语法错误的先排除

---

## 四、考场时间与策略易错

- 选择题死磕超过 2 分钟就先跳过
- 阅读程序最容易超时，建议每大题控制在 12–15 分钟
- 完善程序最后做，但至少留 25 分钟
- 填答题卡时题号别对错位（尤其阅读/完善有很多小题）

## 五、建议复习方式
1. 把本文件打印或复制到错题本
2. 每做完一套真题，对照这里的点检查自己是否踩坑
3. 考前一天快速过一遍即可，不要再学新知识
