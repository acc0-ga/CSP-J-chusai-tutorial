# 树状数组完整可运行示例 + 图解

本文提供一个**可以直接编译运行**的树状数组示例，并配合文字图解帮助理解 lowbit 的跳跃过程。

---

## 一、完整可运行代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 1005;
int tree[MAXN];   // 树状数组
int n;            // 数组大小（1-based）

// 核心：lowbit
int lowbit(int x) {
    return x & -x;
}

// 单点修改：把位置 i 的值加上 v
void update(int i, int v) {
    while (i <= n) {
        tree[i] += v;
        i += lowbit(i);   // 跳到父亲节点
    }
}

// 前缀和查询：求 1~i 的和
int query(int i) {
    int sum = 0;
    while (i > 0) {
        sum += tree[i];
        i -= lowbit(i);   // 跳到前一个区间
    }
    return sum;
}

// 区间和 [l, r]
int range_sum(int l, int r) {
    return query(r) - query(l - 1);
}

int main() {
    // 示例：维护一个长度为 8 的数组，初始全 0
    n = 8;
    memset(tree, 0, sizeof(tree));

    // 进行几次修改
    update(1, 3);   // a[1] += 3
    update(2, 1);   // a[2] += 1
    update(3, 4);   // a[3] += 4
    update(5, 2);   // a[5] += 2
    update(8, 5);   // a[8] += 5

    // 此时逻辑数组 a 相当于：[3, 1, 4, 0, 2, 0, 0, 5]

    cout << "前缀和 1~3 = " << query(3) << endl;      // 应该是 3+1+4 = 8
    cout << "前缀和 1~5 = " << query(5) << endl;      // 3+1+4+0+2 = 10
    cout << "区间和 2~5 = " << range_sum(2, 5) << endl; // 1+4+0+2 = 7
    cout << "区间和 1~8 = " << range_sum(1, 8) << endl; // 全部 = 15

    // 再修改一次
    update(3, 10);  // a[3] 再加 10，变成 14
    cout << "修改后 前缀和 1~3 = " << query(3) << endl; // 3+1+14 = 18

    return 0;
}
```

**预期输出**：
```
前缀和 1~3 = 8
前缀和 1~5 = 10
区间和 2~5 = 7
区间和 1~8 = 15
修改后 前缀和 1~3 = 18
```

把代码复制到任意 C++ 环境（Dev-C++、VS Code、在线 IDE）即可直接运行。

## 三、图解：一次 update 的过程

假设执行 `update(3, 4)`（给位置 3 加 4）：

```
起始 i = 3

第1步：tree[3] += 4
       i = 3 + lowbit(3) = 3 + 1 = 4

第2步：tree[4] += 4
       i = 4 + lowbit(4) = 4 + 4 = 8

第3步：tree[8] += 4
       i = 8 + lowbit(8) = 8 + 8 = 16  > n=8，停止
```

所以位置 3 的修改影响了节点 **3、4、8**。

---

## 四、图解：一次 query 的过程

假设查询 `query(6)`（求前缀和 1~6）：

```
起始 i = 6，sum = 0

第1步：sum += tree[6]
       i = 6 - lowbit(6) = 6 - 2 = 4

第2步：sum += tree[4]
       i = 4 - lowbit(4) = 4 - 4 = 0，停止
```

累加了节点 **6 和 4**，正好对应区间 [5,6] + [1,4] = [1,6]。
