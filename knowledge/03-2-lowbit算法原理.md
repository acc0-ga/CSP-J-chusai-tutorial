# lowbit 算法原理深入讲解

`lowbit(x)` 是位运算中非常经典的操作，定义为：

```cpp
int lowbit(int x) {
    return x & -x;
}
```

它的作用是：**取出 x 的二进制表示中最低位的 1，以及它后面的所有 0**（即最低的一个“1”所在的那一截）。

---

## 一、直观例子

| x（十进制） | x 的二进制 | -x 的二进制（补码） | x & -x | 结果含义 |
|-------------|------------|---------------------|--------|----------|
| 12          | 1100       | ...0100             | 0100   | 4        |
| 10          | 1010       | ...0110             | 0010   | 2        |
| 8           | 1000       | ...1000             | 1000   | 8        |
| 7           | 0111       | ...1001             | 0001   | 1        |
| 6           | 0110       | ...1010             | 0010   | 2        |
| 1           | 0001       | ...1111             | 0001   | 1        |
| 0           | 0000       | 0000                | 0000   | 0        |

可以看到，结果正好是「最低的那个 1」所代表的权值。

---

## 二、为什么 x & -x 能取出最低位的 1？（核心原理）

这完全依赖**补码**的性质。

### 1. 回顾补码中 -x 的求法
```
-x = ~x + 1
```

### 2. 逐步推导

假设 x 的二进制为：
```
... a 1 0 0 ... 0
       ↑
     最低位的1
```

对它按位取反 `~x`：
```
... ~a 0 1 1 ... 1
```

再加 1：
```
... ~a 1 0 0 ... 0
```
（加1时，从最低位开始进位，把后面的1全部变成0，并在原来最低1的位置进位变成1）

此时 `-x` 变成：
```
... ~a 1 0 0 ... 0
```

现在做 `x & -x`：
```
x:    ... a 1 0 0 ... 0
-x:   ...~a 1 0 0 ... 0
& 结果: ... 0 1 0 0 ... 0
```

最高位到最低1左边的所有位都被清零，只剩下最低的那个1及其后面的0。  
**这就是 lowbit 的全部原理。**

### 3. 一句话总结
补码的 `-x = ~x + 1` 会把 x 最低位1右边的所有0变成1，并把这个1变成0，同时产生进位；再与原 x 做与运算，就只剩下这个最低1。

## 三、常见应用（CSP-J / 复赛都会用到）

### 1. 判断一个数是不是 2 的幂
```cpp
bool isPowerOfTwo(int x) {
    return x > 0 && (x & -x) == x;
    // 或者 x > 0 && (x & (x-1)) == 0
}
```

### 2. 统计二进制中 1 的个数（Brian Kernighan 算法）
```cpp
int countOnes(int x) {
    int cnt = 0;
    while (x) {
        x -= lowbit(x);   // 或者 x &= (x-1);
        cnt++;
    }
    return cnt;
}
```
每次减去（或消掉）最低位的1，循环次数就是1的个数。

### 3. 树状数组（Binary Indexed Tree）的核心
树状数组中，节点 i 管辖的区间长度正好是 `lowbit(i)`。  
这也是为什么树状数组能这么高效的原因。

### 4. 枚举所有非空子集（状态压缩常用）
```cpp
for (int s = x; s; s = (s-1) & x) {
    // s 是 x 的一个非空子集
}
```

### 5. 获取最低位1的位置（从0开始）
```cpp
int pos = __builtin_ctz(x);          // GCC内置，数尾随0的个数
// 或者手写：
int getPos(int x) {
    int pos = 0;
    while ((x & 1) == 0) {
        x >>= 1;
        pos++;
    }
    return pos;
}
```

---

## 四、相关易错点与注意

1. **x = 0 时**  
   `lowbit(0) = 0`，循环时要注意终止条件，否则会死循环。

2. **负数**  
   对负数使用 `x & -x` 在补码下仍然有定义，但通常我们只对正数使用 lowbit。考试中如果出现负数，要特别小心。

3. **和 `x & (x-1)` 的区别**
   - `x & -x`：**保留**最低位的1（取出它）
   - `x & (x-1)`：**消除**最低位的1

   两者经常一起出现，不要搞混。

4. **溢出问题**  
   在 32 位 int 下，`x = INT_MIN`（-2147483648）时，`-x` 会溢出，结果仍是它自己。这种情况要特殊处理。

5. **优先级**  
   写表达式时记得加括号：`if ((x & -x) == x)`

## 六、一句话记住

> **lowbit(x) = x & -x**  
> 利用补码“取反加一”的进位特性，瞬间定位并取出最低位的1。

它是连接「补码」和「高效位运算技巧」的桥梁，也是树状数组、状态压缩、位运算优化的基础。
