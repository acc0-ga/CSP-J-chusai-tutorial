# 补码机制深入讲解（CSP-J 必会）

补码是计算机存储**有符号整数**的方式。理解补码后，很多位运算的「奇怪现象」就会变得理所当然。

---

## 一、为什么需要补码？

计算机只认识 0 和 1，没有“负号”这个符号。  
早期有原码、反码，但它们有两个大问题：

1. **+0 和 -0 表示不唯一**（浪费编码，判断麻烦）
2. **加减法电路复杂**（需要根据符号决定做加法还是减法）

补码完美解决了这两个问题：
- 0 的表示唯一
- 加减法可以用同一套电路（把减法变成加法）

---

## 二、补码是怎么定义的？

以 **8 位** 为例（实际 int 是 32 位，道理完全一样）：

### 1. 正数的补码
正数的补码 = 原码（最高位是符号位 0）

```
+5 的原码/补码：  0000 0101
```

### 2. 负数的补码
有两种等价求法（记住一种就行）：

**方法 A（推荐）**：  
对应正数的二进制 → 按位取反 → 再加 1

```
-5：
  +5：     0000 0101
  取反：   1111 1010
  加 1：   1111 1011     ← 这就是 -5 的补码
```

**方法 B**：  
用模运算理解：n 位补码中，-x 的值等价于 2ⁿ - x

```
8 位下：-5 = 256 - 5 = 251
251 的二进制 = 1111 1011（和上面一样）
```

### 3. 特殊值
| 数值 | 8 位补码 | 说明 |
|------|----------|------|
| 0    | 0000 0000 | 唯一 |
| +127 | 0111 1111 | 最大正数 |
| -128 | 1000 0000 | 最小负数（注意：没有 +128） |
| -1   | 1111 1111 | 全 1 |

**重要结论**：  
- 8 位有符号范围是 **-128 ~ +127**  
- 32 位 int 范围是 **-2³¹ ~ 2³¹-1**（约 -21亿 ~ +21亿）

## 三、补码的核心性质（考试常考）

### 性质 1：~x = -x - 1

按位取反后再加 1 就是取相反数，所以：

```cpp
~x + 1 = -x
⇒  ~x = -x - 1
```

例子：
```cpp
int x = 5;
cout << ~x;    // 输出 -6
```

### 性质 2：-1 的补码是全 1

```cpp
int x = -1;    // 32 位全是 1：1111...1111
cout << (x & 7);   // 结果是 7
cout << (x >> 1);  // 结果还是 -1（算术右移补 1）
```

### 性质 3：补码加减法可以直接当无符号算

计算机内部把所有数都当成补码，做二进制加法，溢出位直接丢掉，结果自动正确（在不溢出的前提下）。

例子（8 位）：
```
  0000 0101   (+5)
+ 1111 1011   (-5)
------------
  0000 0000   (0)   ← 完美
```

### 性质 4：算术右移保持符号

有符号数右移时，高位补**符号位**（正数补 0，负数补 1），这样数值上相当于除以 2 并向下取整。

```cpp
int x = -8;        // 1111 1000（8位示意）
x >> 1;            // 1111 1100  → -4
```

## 四、常见陷阱与易错点

1. **以为负数最高位只是“负号”，后面是原码**  
   错！后面是取反加一后的结果，不是原码。

2. **认为 ~5 应该是正数**  
   实际是 -6。

3. **右移负数时期望补 0**  
   有符号数是算术右移，补的是 1。

4. **忽略“最小负数没有对应正数”**  
   `-2147483648` 取相反数会溢出（还是它自己）。

5. **把补码和原码、反码混用**  
   现在几乎所有计算机都用补码，考试默认也是补码。

---

## 五、快速互化口诀

- **正数 → 补码**：直接写二进制，最高位补 0
- **负数 → 补码**：对应正数二进制 → 取反 → 加 1
- **补码 → 数值**：
  - 最高位是 0 → 就是正数本身
  - 最高位是 1 → 取反加 1，前面加负号

## 六、真题风格小练习

**1.** 8 位补码 `1111 1011` 表示的十进制数是？  
答案：-5

**2.** `int x = 0; cout << ~x;` 输出什么？  
答案：-1

**3.** 为什么 `-1 >> 1` 的结果还是 `-1`？  
答案：-1 的补码是全 1，算术右移高位补 1，结果仍是全 1。

**4.** 写出 -1、-2、-128 的 8 位补码。  
答案：  
-1：1111 1111  
-2：1111 1110  
-128：1000 0000

## 七、和位运算的关系总结

理解补码后，这些现象就通了：

| 现象 | 原因 |
|------|------|
| `~x = -x-1` | 取反加一是取相反数的定义 |
| `-1` 全 1 | 2ⁿ - 1 的二进制 |
| 负数右移补 1 | 算术右移保持符号位 |
| `x & -x` 取 lowbit | 利用了补码 `-x = ~x + 1` 的性质 |
